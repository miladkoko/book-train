# ریاضیات مالی (Financial Mathematics)

این پوشه جزوه و مسیر یادگیری گام‌به‌گام ریاضیات مالی است.

## روش آموزش

هر درس با ساختار زیر نوشته می‌شود:

1. شهود و کاربرد مالی
2. تئوری و فرمول‌ها
3. تعریف فارسی همه نمادهای ریاضی
4. مثال عددی قدم‌به‌قدم
5. تمرین تعاملی
6. جمع‌بندی درس

سبک توضیح‌ها از پایه و به زبان ساده (ELI10) است و هیچ نماد جدیدی بدون تعریف رها نمی‌شود.

## سرفصل‌ها

1. جبر خطی و حسابان پیشرفته
2. آمار و احتمال کاربردی
3. تحلیل سری‌های زمانی مالی
4. بهینه‌سازی ریاضی و نظریه مدرن سبد سرمایه
5. حساب دیفرانسیل و انتگرال تصادفی
6. قیمت‌گذاری مشتقات مالی
