# ریاضیات مالی (Financial Mathematics)

این پوشه جزوه و مسیر یادگیری گام‌به‌گام ریاضیات مالی است. کل دوره از ابتدا تا انتها در همین مسیر نگه‌داری می‌شود و هر درس فایل مستقل خودش را دارد.

## روش آموزش و به‌روزرسانی

هر درس با این ساختار نهایی می‌شود:

1. شهود و کاربرد مالی
2. تئوری و فرمول‌ها
3. تعریف فارسی همه نمادهای ریاضی
4. مثال عددی قدم‌به‌قدم
5. تمرین تعاملی
6. فیدبک و اصلاح اشتباهات
7. جمع‌بندی درس

سبک توضیح‌ها از پایه و به زبان ساده (ELI10) است و هیچ نماد جدیدی بدون تعریف رها نمی‌شود.
