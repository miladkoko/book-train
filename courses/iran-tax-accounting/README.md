# دوره حرفه‌ای حسابداری، مالیات و دفاع مالی در ایران

> نسخه پایه: 2026-08-20 | وضعیت: Living Course / خودبه‌روزرسان

## هدف
این دوره یک مسیر صرفاً نظری نیست. هدف، تربیت فردی است که بتواند چرخه واقعی مالی یک کسب‌وکار ایرانی را از سند حسابداری تا بستن حساب‌ها، اظهارنامه، سامانه‌ها، رسیدگی، لایحه و دفاع مدیریت کند و هم‌زمان برای مسیرهای «مشاوران رسمی مالیاتی» و «کارشناس رسمی دادگستری – حسابداری و حسابرسی» آماده شود.

## استاندارد ثابت هر درس
قانون → منطق ساده (ELI10) → ثبت/محاسبه حسابداری → سامانه و اجرای واقعی → کنترل و تطبیق → خطا و رفع خطا → رسیدگی/حسابرسی → اعتراض → لایحه → دفاع → پرونده عملی → آزمون → مرور فاصله‌دار.

## روش آموزشی
هر جلسه از Active Recall، Spaced Repetition، Interleaving، Feynman Technique، Worked Examples، Case-based Learning، Socratic Questioning و Deliberate Practice استفاده می‌کند. در جلسات دفاع، مدرس نقش ممیز، حسابرس بیمه، عضو هیأت یا طرف مقابل را می‌گیرد.

## نظام ارزیابی
- Quiz بازیابی از حافظه
- تمرین عددی و ثبت حسابداری
- تکلیف سامانه‌ای/اجرایی
- Case Study
- آزمون تشخیص خطا
- نگارش لایحه
- دفاع شفاهی شبیه‌سازی‌شده
- آزمون جامع هر سطح
- Capstone نهایی

## استاندارد قبولی
دانستن پاسخ کافی نیست. فراگیر باید بتواند: مسئله را تشخیص دهد؛ منبع معتبر پیدا کند؛ محاسبه/ثبت انجام دهد؛ عملیات سامانه‌ای را بفهمد؛ مستندات بسازد؛ مغایرت را رفع کند؛ و در صورت اختلاف، دفاع مستدل ارائه کند.

## سیاست منابع و به‌روزرسانی
منابع به ترتیب اعتبار: قوانین و مقررات رسمی → آیین‌نامه/تصویب‌نامه → بخشنامه/دستورالعمل → آرای مراجع صالح → راهنمای رسمی سامانه → استانداردهای حسابداری → منابع دانشگاهی/حرفه‌ای → دوره‌ها و کلاس‌های اساتید به‌عنوان Benchmark.

هر موضوع اجرایی باید دارای «تاریخ آخرین بازبینی» باشد. تغییر UI سامانه به‌تنهایی کافی نیست؛ در بازبینی باید اثر تغییر بر قانون، فرایند، ثبت حسابداری، تمرین، Case و آزمون بررسی شود.

## ساختار آتی مخزن
- `modules/` درس‌های تفصیلی
- `labs/` آزمایشگاه‌های سامانه‌ای و عملی
- `cases/` پرونده‌های شبیه‌سازی‌شده
- `pleadings/` تمرین‌های لایحه و دفاع
- `exams/` آزمون و بانک سؤال
- `references/` فهرست منابع معتبر و تاریخ بازبینی
- `updates/` Change Log قوانین و سامانه‌ها
- `templates/` چک‌لیست‌ها، Working Papers و الگوهای آموزشی

## هشدار حرفه‌ای
این مخزن برای آموزش است. قوانین، بخشنامه‌ها، رویه‌ها و سامانه‌های ایران تغییر می‌کنند؛ برای اقدام واقعی باید نسخه جاری منبع رسمی و شرایط پرونده مشخص بررسی شود.
