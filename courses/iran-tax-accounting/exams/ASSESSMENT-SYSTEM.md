# نظام آزمون و Mastery

## چرخه هر درس
Pre-test → Lesson → Worked Example → Guided Practice → Independent Case → Retrieval Quiz → Feedback → Re-test.

## مرور
D+1: پنج سؤال بازیابی؛ D+7: مسئله تغییرشکل‌یافته؛ D+30: Interleaved Case؛ D+90: Cumulative Case.

## انواع سؤال
- Explain: با زبان ساده چرا؟
- Calculate: عدد را با Working نشان بده.
- Execute: فرایند سامانه/کار را اجرا یا شبیه‌سازی کن.
- Diagnose: خطا را پیدا کن.
- Research: منبع جاری را پیدا و اعتبارسنجی کن.
- Defend: موضع مخالف را پاسخ بده.
- Transfer: مسئله جدیدی که عین مثال درس نیست.

## قانون Mastery
نمره کلی بالا ضعف حیاتی را پنهان نمی‌کند. Accuracy قانونی، صحت محاسبه، Evidence Integrity و Deadline Awareness Gate هستند.

## Error Log
برای هر خطا ثبت کن: سؤال، پاسخ من، پاسخ صحیح، علت ریشه‌ای، نوع خطا، نشانه‌ای که نادیده گرفتم، قانون/مفهوم لازم، تمرین ترمیمی، تاریخ Retest.

## Adaptive Teaching
اگر دو خطای متوالی مفهومی رخ داد: آموزش ساده‌تر + مثال ملموس. اگر خطا محاسباتی بود: Worked Example و سپس Faded Example. اگر خطا در Transfer بود: دو Case متفاوت. اگر پاسخ حفظی بود: سؤال «چرا/اگر برعکس شود؟». اگر اعتماد بیش از دقت بود: Confidence Score کنار پاسخ ثبت شود.

## آزمون شفاهی دفاع
فراگیر ابتدا 3 دقیقه بدون وقفه دفاع می‌کند؛ سپس 7 دقیقه سؤال سخت. امتیاز بر اساس انسجام Facts-Evidence-Law-Calculation است، نه فن بیان صرف.
