# دوره جامع Finance & FP&A — نسخه ایران

> یک دوره زنده و مرحله‌ای برای یادگیری مالی، برنامه‌ریزی و تحلیل مالی (FP&A) از پایه تا سطح حرفه‌ای.

## هدف نهایی
در پایان دوره باید بتوانی صورت‌های مالی را بخوانی و به هم متصل کنی، عملکرد کسب‌وکار را تحلیل کنی، بودجه و Forecast بسازی، انحراف Actual vs Budget را توضیح دهی، مدل مالی و سناریو بسازی و نتیجه را به زبان مدیریتی ارائه کنی.

## فلسفه آموزش
- توضیح اولیه بسیار ساده (ELI10)، سپس افزایش تدریجی عمق
- یادگیری فعال: مثال → تمرین → بازخورد → Case → آزمون
- تمرکز بر فهم علت‌ها، نه حفظ فرمول
- مثال‌های ایرانی: تومان/ریال، تورم، ارز، سرمایه در گردش، اعتبار، مالیات و تأمین مالی
- Excel از ابتدا همراه درس؛ سپس Power Query، Power BI و SQL
- دوره زنده است و براساس عملکرد یادگیرنده و تغییر ابزارها بهبود می‌یابد.
